# python-learning

Personal repo where I learned Python fundamentals from scratch.

## Why this repo exists

I'm a Systems Engineering student (UTN) who built a solid Python foundation here — mostly on my own, outside of what the university covers. Instead of following a course exercise-by-exercise, most of the code is **integrative challenges**: I learned a new concept, and the exercise combined it with everything I already knew. Each one got progressively harder and more realistic.

**Status:** ✅ Fundamentals phase complete. This repo now stays as-is — a reference for Python syntax and concepts.

## Structure

- **[`exercises/`](./exercises)** — Python fundamentals practice. See its own README for the topic progression.

## Stack

Python 3.x — no external dependencies for the fundamentals exercises.
