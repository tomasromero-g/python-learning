# python-learning

Personal repo where I track my Python learning journey — from fundamentals to backend development with FastAPI.

## Why this repo exists

I'm a Systems Engineering student (UTN) building a solid Python foundation — mostly on my own, outside of what the university covers. I want to get hands-on with the tools and stack actually used in backend jobs, not just pass the coursework. Instead of following a course exercise-by-exercise, most of the code here are **integrative challenges**: I learn a new concept, and the exercise combines it with everything I already know. Each one gets progressively harder and more realistic.
